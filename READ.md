# Hangman

A console Hangman game in Python with word categories and a hint option.

## Features

- Three word categories loaded from a JSON file
- Hint option that reveals a letter at the cost of one life
- ASCII hangman drawings
- Input validation and a win/loss record

## How to run

1. Install Python 3
2. Run: `python hangman.py`

- Reading data from JSON files
